## 设计说明（约 500 字）

**风格与取舍。** 本方案走"现代企业风·冷静可信"：大量留白 + 1px 细边框 + 极浅阴影（`0 1px 3px rgba(16,24,40,.07)`）替代重投影，让界面安静下来——因为产品的核心价值是"结论可信"，视觉噪音越少，数字越有分量。主要取舍：放弃了更强的视觉冲击（深色科技风、大渐变），换取小白用户的"不吓人"与汇报场景的专业感，与评审标准中权重最高的"品牌一致性 + 专业可信"（合计 50%）对齐。

**令牌兼容。** 基础 10 令牌原样保留；按 §七-A 建议扩展了**等色温灰阶 50~900**（与 `#1A1D23` 同源，灰阶之间色温一致，不会出现"脏灰"）与**语义色**（success/info/warning/danger）。语义锁定规则全部保留：品牌蓝只出现在按钮/链接/导航/选中态；情感三色只出现在图表、图例、语义标签；悬停只做 `brightness()/opacity()` 变化。warning 采用琥珀色 `#B45309`（对白底 4.5:1，达 AA），与负面红 `#D94A4A` 拉开语义距离——现状里"采集不足"和"负面情绪"共用一个红，是语义混淆点。

**字体与数字。** 系统字体栈（微软雅黑/苹方，遵守 §七-G 不引入思源黑体）；所有指标数字用 `font-variant-numeric: tabular-nums` + Bahnschrift/Segoe UI 数字栈，等宽数字保证刷新时列不跳动，这是"报表感 → 产品感"最便宜的一步（P0-4）。

**记忆点。** ① 报告封面从"渐变 banner"改为**白底封面卡 + 品牌色顶带 + 报告编号**，像正式交付物；② 顶部统一的 logo 标记（对话气泡 + 横线，寓意"把声音读平"）；③ 情感标签 `✓/✗/～ + 色点` 三件套贯穿三端，成为可识别的视觉资产。产品名暂用"社交媒体情感分析器"，待 §七-E 拍板。

**结论优先（命题 B）。** 首屏严格按 §6-4 线框：一句话结论（含可信度胶囊 + 待复核警示）→ 4 指标卡 → 唯一默认展开的情感占比主图；其余 11 图折叠为"标题 + 一句摘要 + 风险徽标"的钻取行，用户不展开也能扫完全局。

**可访问性。** 正文/背景对比 4.5:1+（AA）；情感信息永不单靠颜色（✓/✗/～ 叠加保留）；按钮/触控目标 ≥44px；`:focus-visible` 键盘焦点环；`prefers-reduced-motion` 关闭旋转动画。已知边界：品牌蓝 `#2B7BD6` 白字实测约 4.3:1，属 AA 边界值——主按钮文字统一 ≥15px 加粗（大文本标准 3:1 达标），且悬停加深至 `#1F5F9E`（约 6.3:1）；不改品牌令牌本身。

## 令牌速查

```css
/* 基础（不变） */
--c-brand:#2B7BD6; --c-brand-hover:#1F5F9E;      /* 按钮/链接/导航 */
--c-pos:#2E9A6E; --c-neu:#8C8C8C; --c-neg:#D94A4A; /* 仅图表/标签 */
--c-page:#F8F9FA; --c-card:#FFF; --c-text:#1A1D23; --c-border:#DEE2E6;
/* 扩展 · 灰阶 */
--g-50:#F8F9FA → --g-900:#1A1D23（等色温 10 阶）
/* 扩展 · 语义色（仅状态条/图标/边框） */
--s-success:#2E9A6E; --s-info:#2B7BD6; --s-warning:#B45309; --s-danger:#D94A4A;
/* 圆角 6/10/14 · 阴影 xs~md 三档 · 间距 4/8/12/16/24/32/48 */
```
