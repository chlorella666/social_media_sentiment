# 社交媒体情感分析器（Social Media Sentiment Analyzer）

本地 Web 应用：输入品牌/产品名（或手输关键词），以向导方式确认分析维度、关键词、采集渠道和时间段，自动完成社交媒体数据采集 → 情感编码 → 图表 → 报告，输出原始数据 Excel 和 HTML/Word 分析报告。

## 快速开始

### 方式一：双击启动（Windows）

双击 `run.bat`，浏览器会自动打开应用（首次运行会自动安装依赖）。

### 方式二：命令行

```bash
pip install -r requirements.txt
python -m streamlit run app/main.py
```

## 使用流程

1. **输入分析对象**：输入品牌/产品名 + 选择领域（游戏/消费品），或直接手输关键词
2. **确认维度**：勾选要分析的维度（可增删改）
3. **确认关键词**：查看按维度生成的建议词，可编辑；也可切到手动模式
4. **选择渠道与时间**：勾选采集渠道、设置起止日期
5. **确认计划并运行**：查看汇总计划 → 启动，实时查看进度
6. **下载结果**：Excel（原始数据/编码明细/统计汇总）、HTML 交互报告、Word 报告

> MVP 默认使用"演示数据"渠道，无需任何登录即可跑通全流程。真实采集渠道（微博/知乎/B站/小红书/WebSearch）的适配器接口已就绪，将在 V1 接入。

## 大模型配置（可选）

情感分析默认使用内置词典预筛（离线可用）。如需 LLM 精分析，在应用侧边栏配置：

- **服务商预设**：选择「DeepSeek」会自动填好 Base URL 与模型名，只需粘贴 API Key
- API Key
- Base URL（OpenAI 兼容接口）
- 模型名

DeepSeek 推荐配置：

| 项 | 值 |
|----|----|
| Base URL | `https://api.deepseek.com` |
| 模型名 | `deepseek-chat`（批量情感分析）或 `deepseek-reasoner`（较慢） |

填好后点击侧边栏「测试连接」可立即验证配置。连接失败时应用会给出明确原因
（Key 无效 / 余额不足 / 模型不存在 / 网络不通），并自动降级为词典模式继续分析。

也可通过环境变量 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_MODEL` 配置。未配置时自动降级为词典模式。
