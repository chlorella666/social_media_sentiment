## 二、试用步骤清单（每步记录：顺利 ✓ / 卡住 ✗ + 现象）

> 目标：从「解压完成」到「demo 渠道出报告」≤10 分钟，全程无需命令行。

- [ ] 1. 解压（若报“路径太长”：v0.1.4 起已修复；仍报则改用 7-Zip 或短路径目录）
- [ ] 2. 双击「启动应用.bat」（黑窗是否乱码？SmartScreen/杀软是否拦截？按随包指引「解除锁定/仍要运行」）
- [ ] 3. 浏览器自动打开（未自动打开→手动访问 http://localhost:8501）
- [ ] 4. 首次出现《使用边界》确认页，**内容完整可读**（v0.1.7 已随包提供）→ 勾选并确认
- [ ] 5. 点「✨ 看演示报告」→ 是否约 2 秒出成品报告
- [ ] 6. 向导：品牌名随便填 → 渠道只勾「演示数据」→ 下一步 → 确认运行
- [ ] 7. 后台执行页：能看到进度，约 1 分钟出报告（是否出现“后台执行进程未运行”？如出现可点「🔄 启动后台进程」）
- [ ] 8. 结果页：结论、图表正常；下载 Excel 与 HTML 报告成功
- [ ] 9. （可选）下载 Word 报告：首次约 30~60 秒属正常
- [ ] 10. 双击「退出.bat」→ 再次双击「启动应用.bat」应提示“已在运行”（防重复启动）
- [ ] 11. （进阶，不引导）B站渠道小规模试跑：是否出数正常

## 四、已知问题核对表（遇到时不必重复上报，按提示操作即可）

| # | 已知项 | 说明 |
|---|---|---|
| 1 | Word 首次生成慢 | 需渲染图表图片，约 30~60 秒，属正常 |
| 2 | WebSearch 采集量偏少 | 单查询最多 13 条，受平台风控限制 |
| 3 | 词典模式准确率约 47%~51% | 未开 LLM 时反讽/黑话/方言偏弱 |
| 4 | 演示数据是模拟帖 | 仅用于跑通流程，不代表真实平台内容 |
| 5 | 微博/小红书需凭据且易风控 | 首轮不建议勾选；opencli 一键安装为进阶 |

| 7 | 杀软弹窗 | 选择「允许/仍要运行」；zip 右键属性→解除锁定 |

## 反馈汇总建议（拿到反馈后）

1. 按严重度排序，**阻断项**优先修；
2. 相同现象多人遇到 = 高优先级；
3. 反馈涉及日志时，对照 `data/logs/app.jsonl` 的 task_logs 定位失败步骤；
4. 修完后按 `v0.1.x` 递增版本重建，并在新版「已知问题」中更新已修复项。
