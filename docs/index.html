Problem

为什么做这个产品

中小主体做品牌口碑调研，四个痛点长期存在

商业工具太贵

舆情 SaaS 年费数万起步、需商务报价，个人和小团队根本用不起。

人工整理不可持续

手动搜索 + Excel 整理，耗时且主观，无法规模化复用到多个品牌。

数据隐私顾虑

云端 SaaS 要上传账号凭据与内容；本项目默认本地离线、加密存储。

质量不透明

多数工具不公布准确率、结论不可追溯；本项目自建评测集与基线门槛。
