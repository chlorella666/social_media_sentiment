# 受控对照跑分操作单（WebSearch 关键词策略验证）

> 目的：用"除策略配置外完全一致"的两次任务，判定关键词策略改动是否真的有效。
> 判定口径（2026-08-13 分档修订）：基准整体有效率 <85% 用**提升验证**（整体有效率
> 较基准 ≥ +5pp）；基准 ≥85%（近天花板）用**扩容验证**（同查询串不降 ±1pp +
> 新增查询串有效率 ≥80% + 有效文本增量显著）；两种口径都要求纯品牌词丢弃率
> **<15%**、判定查询串 n≥30；**≥2 个品牌**达标才算关键词闭环验证通过。
> 完整定义见 docs/评测记录.md「2026-08-13 受控对照口径修订」。

## 前置准备

- 打开评测中心（`eval.bat`，或主应用"开发者模式"→ 启动评测中心）；
- 选一个品牌（建议 大疆 / 华润万家 / 恋与深空）；
- 关键词列表：**建议包含裸品牌名**（如"华润万家"），否则纯品牌词指标无法判定；
- 渠道：**只勾 WebSearch**（含知乎/贴吧/TapTap 子渠道）；
- "关键词优化"开关：**固定一个状态**（推荐开），两次必须一致；
- 时间段：两次任务保持一致。
- 注意：WebSearch 每关键词上限已封顶 13（单查询可获取量约 5~13 条）；
  要更多样本请加查询词（策略加词），不要调大上限。
- 频率约束：聚合确认是重活，**每天 ≤2 轮、轮间 ≥10 分钟**
  （`tests/run_keyword_confirm.py` 已内置拦截），避免触发 WebSearch 风控。

## 第 1 步：跑基准任务

按上述配置在向导里跑一次任务，等任务完成。

## 第 2 步：入库并记住基准

评测中心 → 关键词效果 → 点"**扫描 data/reports 并刷新**"。
在"前后对照"里把"基准任务（旧）"记成这一次。

## 第 3 步：改策略

- 候选确认写入（或在"🎛 关键词策略配置"页直接编辑）；
- 建议一次只加/删**一批词**，方便归因到底是谁起的作用。

## 第 4 步：跑对照任务

用**完全一样**的配置再跑一次（关键词/渠道/后缀开关/时间段都不动）→ 回评测中心扫描。

## 第 5 步：读判定

"前后对照"里选 基准=旧、本次=新，看四个结果：

1. **有效供给率卡片**：按分档口径判定——低基准（<85%）看整体是否 +5pp；
   高基准（≥85%）看"同查询串不降 + 新增词质量 + 有效文本增量"（见「达标判定」）；
2. **纯品牌词丢弃率卡片**：是否 <15%（任务没有品牌名关键词时会显示"无法判定"）；
3. **新增查询串卡片**：新增词带没带来有效内容（采集/保留/有效供给率）；
4. **低效词删除建议**：按"强建议删除 / 弱建议（参考）"处理，点"一键删除"即可从策略配置移除。

## 第 6 步：修枝再测（可选）

删除低效词后，重复第 4~5 步，看整体有效率是否回升；直到达到判定口径。

## 常见坑

- 两次任务改了关键词、渠道或后缀开关 → 对照无效，重跑；
- 样本 <30 → 数字波动大，标"参考"，先别下结论；
- 同一查询串多轮跑分结果高度重合，直接求和会把 n 虚高（小象超市 9 轮「评价」
  12→72，去重后实为 12）；跨任务聚合必须先按 URL（或标题前 50 字）去重；
- 基准有效率已 ≥85% 时，"整体 +5pp"数学上不可达，用扩容验证口径看
  "同查询串不降 + 新增词质量 + 增量"，不要误判为下降；
- 纯品牌词指标要求关键词列表里有"裸品牌名"；
- 新增词单个 100% 保留 ≠ 整体达标（可能被知乎/贴吧等子渠道拉低）；
- 判定只看"同一查询串"或"整体有效率"，不要混着比。

## 达标判定

- 基准整体有效率 <85%（提升验证）：整体有效供给率较基准 ≥ +5pp；
- 基准整体有效率 ≥85%（扩容验证，接近天花板时整体率必然被新词稀释）：
  同查询串有效率不降（±1pp 内）＋ 新增查询串有效率 ≥80% ＋ 有效文本增量显著
  （新增保留 ≥30 条或相对增长 ≥50%）；
- 两种口径都要求纯品牌词丢弃率 <15%，判定查询串 n≥30（不足标"参考"）；
- n≥30 可通过**同一查询串多次跑分跨任务聚合**达成，但必须先**按 URL（或标题前 50 字）
  跨任务去重**再统计 n 与有效供给率——同一内容只计一次，重复测量只验证比率稳定、
  不放大样本（`tests/run_keyword_confirm.py` 已内置去重聚合）；
- 关键词闭环验证通过：**≥2 个品牌**达标
  （2026-08-13 修订：恋与深空提升验证达标；小象超市跨任务去重后比率稳定但品质
  75% 未达 80% 门槛且 n<30，**待第 2 品牌严格达标**）；
- 记录：把两次任务的时间和判定数字记入 `docs/评测记录.md`。
