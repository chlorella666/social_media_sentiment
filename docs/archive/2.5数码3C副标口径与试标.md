## 二、表结构与字段取值

表头 20 列 = 6 预填列 + 7 维度列 + 7 标注列：

| 预填列（勿改） | 维度列（你填） | 标注列（你填） |

| text_id / 原文 / 平台 / 品牌·主题 / 关键词 / 文本类型 | 功能效果 / 安全合规 / 价格价值 / 渠道服务 / 品牌形象 / 竞品对比 / 设计与做工 | 情感(整条) / 强度(1-5) / 语言现象 / 是否相关 / 备注 / 标注人 / 标注日期 |

取值规则：

| 列 | 取值 | 说明 |
|---|---|---|
| 情感(整条) | positive / negative / neutral / mixed | mixed 严格限制 <2%（能拆维度就不给） |

| 是否相关 | yes / no | no → 情感 neutral、维度全空（不计入主评分） |
| 备注 | 文本 | 歧义理由、黑话含义（标了黑话必写）、同维度另一方向 |
| 标注人 | `trae` | 固定 |
| 标注日期 | `2026-08-15` | 固定 |

## 三、定稿口径（7 条，必须遵守）

> 以下 7 条是 workbuddy 主标与用户共同确认的定稿口径，副标须一致执行。

### 1. 整条情感「跟本品牌」
- 工作表「品牌/主题」列是锚定品牌。**整条情感按本品牌定**，不是按文本情绪定。
- 典型场景：brand=影石，但文本在夸大疆（竞品）→ 对本品牌（影石）是负面 → **整条定 negative**，竞品对比维度标 negative。
- 反例：brand=影石，文本推荐影石 → 整条 positive。
- 即：文本夸竞品贬本品牌 = 整条 negative；文本夸本品牌 = 整条 positive。

### 2. 转折句整条情感「综合定」
- 按「转折后是否带主立场 + 褒贬数量」综合判断，不机械取转折后。
- 客观对比、褒贬均衡 → neutral（如"动态不错但17级吹牛"）。
- 输两项赢一项 → negative（如"价格输硬件输，但软件好用"）。
- 明确推荐某方 → positive（如"参数价格大疆优，但全景选影石"）。

### 3. 同一维度正负并存
- 一条文本对同一维度既有褒又有贬（如功能效果既有"动态不错pos"又有"17级吹牛neg"）：
- **维度列填主评价/作者强调点**（一个值），**另一个方向写进备注**。
- 不要整维留空（除非确实无褒贬）。

### 4. 方向不明的反讽 / 歧义
- 表面正/中性、实际负向 → 反讽，整条 negative。
- 但**方向完全无法判断**（如"天壤之别"看不出更好还是更差）→ **整条 neutral + 备注写"待复核"**，不强制二选一。
- 直接批评不算反讽（反讽只指"表面正向/中性、实际负向"）。
- 高歧义样本（反讽/方向不明）后续 100% 复核。

### 5. relevant 边界
- **标题型问句**（如"华为手机哪个型号性价比高？-知乎"）→ relevant=**yes**（主题相关，即便无观点）。
- **纯无内容**（如单字"?"、单字品牌名"大疆"、纯 emoji）→ 看语境：在品牌相关帖子下评论判 yes，完全无信息判 no。
- **跑题**（主体非该品牌产品评价，如股市分析联想仅作论据、谈柯洁、职场话题）→ relevant=**no**。
- **样板/页面壳**（贴吧用户列表、TapTap 主页碎片、电商参数页标题）→ relevant=**no**。
- relevant=no → 情感 neutral、维度全空。

### 6. 官方宣发 / 广告
- 官方发言转述、官方发布会宣传、官方贴吧活动汇总 → **neutral + 语言现象标"官方" + 维度全留空**（不叠标"无观点"）。
- 代言人活动、新品预约宣传、转评抽奖 → **neutral + 标"广告"**。
- 官方只标"官方"，不叠"无观点"；广告标"广告"。

### 7. 黑话
- 圈内词/网络词（如 种草/返图/商单/炸鸡/拉胯/爆显存/膈应人/要啥自行车/老登/买个der/电子阳痿/higo）→ 标"黑话"，**备注必写含义**。
- **含义不确定时标"待确认"**（如 higo 疑似华为粉黑贬称但未定论），不要瞎猜。

## 六、其余 140 条的标注要点（给副标的提示）

以下是 workbuddy 在剩余 140 条里遇到的高频模式，副标注意对齐（不剧透具体判定，只给模式提醒）：

- **websearch 系大量是参数页/标题/样板**（ZOL、太平洋、知乎问题标题、贴吧页面壳）→ 多为 neutral + 无观点，relevant 看是否主题相关（标题问句 yes，纯页面碎片 no）。
- **微博短评论多**：购买意愿（"很想拥有""已买"）→ positive 但无维度褒贬，维度留空；纯疑问（"为什么不上市"）→ neutral。
- **竞品对比方向**：影石语境下夸大疆的有多条（难复制、配件通用、内存大）→ 一律跟本品牌定 negative、竞品对比 neg。大疆语境下贬大疆推哈博森的（"炸鸡"）→ negative。
- **黑话高频词**：种草/返图/商单/炸鸡(炸机)/拉胯(差)/爆显存/膈应人/要啥自行车/老登/买个der(买个屁)/电子阳痿(对游戏提不起劲)/香(好)——标黑话必写含义。
- **官方/广告**：大疆官方发布、联想代言人痛楼、新品预约、转评抽奖 → neutral + 官方/广告 + 维度留空。
- **股市跑题**：联想/华为语境下谈股价、加仓、市值 → relevant=no。
- **方向不明的短评**（"跳绿""反正不能赢"等缺上下文）→ neutral + 备注"缺上下文"。

## 七、质量线与提交

- **达标线**：整条情感一致率 ≥0.8、Cohen's kappa ≥0.6、维度级一致率 ≥0.75（口径更细，标准略低）。
- **高歧义样本 100% 复核**：反讽 / 方向不明 / relevant=no。
- **提交**：填好 `coldstart_digital3c_worksheet_trae.xlsx`，标注人=trae、日期=2026-08-15。
- **处理顺序**：双 AI 标注 → 一致性核对（随机 60 条 + 高歧义 100%）→ 人工抽检校准 60 条 → 定版 `coldstart_digital3c_golden.csv`。
