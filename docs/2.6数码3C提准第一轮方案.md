# 2.6 数码3C 提准第一轮方案（失败模式取证 + 改动设计）

> 2026-08-16 | 数据源：3C golden v2（677 条，可评分 569）混合跑分两轮
> 70.7/70.8%（均值 70.75%，基线 v2 已冻结）；取证用 run 20260816_013250
> （166 条错误 / 569 = 29.2%）。训练场 = 迭代集；考试卷 = hold-out 40 条
> （基线 73.1%，剩余 1 次验收）。

## 一、失败模式统计（166 条错误）

| 混淆 | 数量 | 占比 | 典型形态 |
|---|---|---|---|
| neutral→positive | 40 | 24% | 介绍/参数/盘点/标题问句被判正面 |
| positive→neutral | 37 | 22% | 隐晦夸赞/安利/期待漏检（保守化） |
| neutral→negative | 32 | 19% | 提问/犹豫/权衡/无立场短评被判负面 |
| negative→neutral | 30 | 18% | 抱怨被说平（跟本品牌口径漏检） |
| negative→positive | 18 | 11% | 竞品方向反转 / 反讽 |
| positive→negative | 9 | 5% | 情绪词误读 |

按渠道：weibo 76 / bilibili 59 / xiaohongshu 26 / websearch 5。

## 二、三大失败模式（按修复收益排序）

### A. 语体 neutral 边界误判（72 条 = neutral→情感，占 43%，第一主攻）

- **标题型问句/求助**："刷了SteamOS，还能切回win系统吗？"、"osmo360二代镜头能自己换吗？"；
- **参数罗列/盘点对比**："两家最新旗舰在硬件上棋逢对手…"、"大疆无人机分为御/Mavic系列…"；
- **犹豫权衡/购买决策**："这两个之前犹豫了好久，干脆去线下试了下…"；
- **无立场短评**："加油"、"那还说啥，享受着呗"、"我舍不得买"（gold=neutral 口径）。
- 根因：LLM 看到"对比/心仪/惊喜/买"等信号就判情感，未识别"无个人立场"语体。

### B. "跟本品牌"口径缺失（LLM 未收 subject，直接样本 ≥10 条 + 竞品维度错 42 条）

- 文本夸大疆/哈博森（brand=影石/大疆）→ gold 按本品牌判 negative，模型按文本自身判
  positive："实习驾驶证——哈博森，正式驾驶证——大疆，果断哈博森"（brand=大疆）等；
- 竞品对比维度：42 条维度错误涉及竞品对比（gold 有竞品对比而 pred 漏/错："选大疆的
  比较好，各方面都稳定"→gold 竞品对比 negative 但 pred 空）。
- 根因：标注口径 = 整条情感跟锚定品牌（[2.5副标口径](2.5数码3C副标口径与试标.md)），
  LLM 只收文本不收品牌，系统性偏差。

### C. 隐晦/情绪表达漏检（positive→neutral 37 + negative→neutral 30 中的一部分）

- 隐晦夸赞/安利："影石Luna系列很猛"、"Pocket 4P 到底谁更牛（视频安利）"；
- 平淡抱怨："除非影石更新，不然大疆明年不会出5p"（gold negative 判 neutral）。
- 根因：表达含蓄时模型偏保守；与 A 类"保守化"是同一枚硬币的两面——靠更准的判例
  区分"无立场"与"含蓄有立场"。

## 三、第一轮改动设计（三件套，按顺序实施）

### 1. Prompt v3.3（PROMPT_VERSION=8）：语体 neutral 边界 + 判例（主攻，工作量小）

在现有 v3.2 基础上追加（不改变输出 schema，token 增量控制在 ~300 内）：

- **语体 neutral 总则细化**：标题型问句/求助（"还能吗/怎么选/值吗"）→ neutral；
  参数罗列/规格盘点/系列介绍 → neutral；"谁更强/对比"盘点文无个人立场 → neutral；
  购买决策中的犹豫/权衡（"犹豫好久/去线下试"）→ neutral（除非明确站队）；
- **含蓄有立场 vs 无立场判例**（few-shot 6 条）："影石Luna系列很猛"→positive；
  "除非影石更新，不然大疆明年不会出5p"→negative（跟本品牌）；"棋逢对手，都搭载…"
  →neutral；"我舍不得买"→neutral（口径）；"选大疆的比较好，各方面都稳定"→
  neutral 整条 + 竞品对比 negative（跟本品牌口径）；"疯狂心动，但不行得对比对比"
  →neutral（权衡中）。
- **竞品对比维度识别要点**：出现"对比/谁更强/差距/更稳/便宜/配件通用/市占率"等
  对比信号时，竞品对比维度按文本内容标（夸竞品=positive、贬竞品=negative），
  与整条情感（跟本品牌）分开判。

### 2. subject 适配（LLM 收品牌，修 B 类，工作量中等，先量化再实施）

- 改动：`analyze_batch`/benchmark 传入当前任务的锚定品牌（golden 的 brand 列），
  prompt 用户侧增加 `subject` 字段 + 口径指令"整条情感跟锚定品牌，夸竞品=对本品牌
  negative"；
- 成本：每请求 prompt tokens 增加品牌名 + 一行指令（估算 <2%），记录在案；
- 先决：第一轮跑分后若 B 类仍 ≥10 条再上（避免两处改动同时跑无法归因）。

### 3. 词典第二轮（可选，低优先）

- 3C 语体词表：把"对比/参数/盘点/攻略/教程"类信号加入词典 neutral-lean 标记
  （复用官方语体压置信机制），提高直判中性率、减少送 LLM 的语体噪声；
- 只在 1+2 后仍有余量时做。

## 四、验证计划（V3 纪律）

1. 每轮改动**跑 2 次取均值**（n=569，单侧 CI ±3.9pp、两轮 ΔCI ±5.5pp）；
2. 达标判定 = 证据组合：迭代集均值提升（≥+5.5pp 才算统计显著，否则看方向 +
  错误下钻确认）+ **hold-out 第 2 次同向提升**（40 条，基线 73.1%，CI ±19pp）+
  人工抽检无系统性新误判；
3. 跨领域防退化：主集（82.9% 基线）与边界集（81.82% 基线）各 1~2 轮不回退；
4. 止损：两轮无同向提升即回滚（PROMPT_VERSION 常量保留旧版），回到迭代集标注
  数据继续积累。

## 五、实施顺序与预期

1. Prompt v3.3 落 `llm_analyzer.py`（预计救回 A 类 20~40 条）→ 迭代集 2 轮 +
  hold-out 第 2 次 + 主集/边界集防退化各 1 轮；
2. 视结果决定 subject 适配（B 类残余 ≥10 条则上）；
3. 词典第二轮视余量。

> 变量控制（默认）：hold-out 只剩 1 次验收机会，**默认先只做 A**（风险最低、改动小），
> 若 A 在迭代集方向正确但 hold-out 未同向，说明样本不足/改动不足，转数据积累而非
> 追加变量；**用户可拍板 A+B 一起跑**（省 hold-out 次数，代价是归因弱、坏改动不好定位）。

## 六、A 轮实施结果（2026-08-16）

- **已实施**：Prompt v3.3（PROMPT_VERSION=8）——含蓄表达三分 + 无立场语体补强 +
  多品牌无锚定整条 neutral + 竞品对比维度信号词扩充；未改输出 schema。
- **跑分**：3C 迭代集 71.55%（+0.8pp，噪声内）；hold-out 第 2 次 **76.9%**
  （+3.8pp 同向但未超 ±19pp CI）；主集 81.1%、边界集 87.7% 均不回退；
  错误下钻：语体类 72→66（-6，问句/求助类改善），negative 漏检 +3（观察项）。
- **判定**：方向证据成立（同向 + 不回退），幅度未达统计显著 → 不宣称达标；
  hold-out 2/2 用尽，后续判定需重切新卷。
- **下一轮候选**：B（subject 适配）——残余"≥2 品牌词判错"9 条（口径直接相关
  约 5~6 条），预期 +1~1.6pp；或先积累新样本重切 hold-out 再上 B。

## 七、B 轮实施结果（2026-08-16，过渡证据）

- **已实施**：subject 适配——`analyze_batch`/`_request_batch` 增加 subject 参数，
  system 注入"锚定品牌口径"（subject 提供时生效），缓存按 subject 隔离；
  `SUBJECT_DOMAINS={digital3c}`（主集/边界集不传，防退化）；benchmark 按
  (领域, 品牌) 分组传 brand；生产链路 coder 对 digital3c 传 plan.subject。
- **跑分**：3C 迭代集均值 72.5%（vs v2 基线 +1.75pp、vs 仅 A +0.95pp，噪声内）；
  总错 166→154；口径类 direct 修复（negative→positive -3、positive→negative -4、
  ≥2 品牌词判错 9→6）；维度全面改善。主集/边界集不回退。
- **判定**：方向证据增强，仍未超显著性区间；hold-out 无新卷 → 维持"未达标，
  待重切 hold-out"。下一轮判定路径 = 补采 ≥120 条 → 重切新卷。

## 八、第三轮 v3.4 判定（2026-08-16，不达标）

- **改动**（PROMPT_VERSION=9）：报道/资讯/电商页/百科/活动打卡 → neutral；行动信号
  =正面、问题未解决/被劝退=负面；调侃反讽与方向不明 → neutral、反讽对象为产品 →
  negative；subject 口径强化。
- **跑分**：迭代集 74.25%（+3.5pp，三轮连续上升，噪声内）；**hold-out r2 68.6%
  （-5.7pp，方向反，噪声内）**；主集/边界集不回退。
- **判定**：hold-out 未同向 → **不达标**；r2 卷用尽。结论不构成"有害"证据也不构成
  "提升"证据（n=35 噪声 ±16pp）。去向：保留候选 vs 回滚 v3.3+B vs 拆分归因，用户拍板。

## 九、拆分归因（2026-08-16）→ v3.4b（PROMPT_VERSION=10）

- 把 v3.4 四组规则做成 `SMS_V34_RULES` 开关逐组消融（迭代集单轮）：
  v14（subject 强化）+2.3pp 主力；v12（行动信号）+1.4pp；v13（调侃反讽）+1.4pp；
  **v11（报道/资讯）净零且过度中性化（pos→neu +4/neg→neu +2）→ r2 -5.7pp 最可能
  元凶，已去掉**。
- v3.4b = base + 12 + 13 + 14：迭代集两轮 74.0/74.7 → 均值 **74.35%**（保留增益），
  主集 81.7%/边界集 85.0% 不回退；仍未过 hold-out 硬判定（r3 待新数据）。
