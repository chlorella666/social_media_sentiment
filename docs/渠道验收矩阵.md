# 渠道验收矩阵（阶段一）

> 版本：v1.0 | 日期：2026-08-04 | 方法：真实采集试跑（无 LLM，纯采集+词典编码）
> 试跑品牌：恋与深空（游戏）/ 华润万家（零售）/ 大疆（消费品）

## 一、验收标准

| 渠道 | 认证 | 最低数据量 | 必填字段 | 附加要求 | 失败处理 |
|------|------|-----------|----------|----------|----------|
| B站 | 零登录 | 每关键词 ≥3 条视频 | bvid/作者/标题/正文/URL/时间/点赞/转发/评论数 + view/danmaku/coin/favorite/share/category | 评论（启用时）≥1 条 | 降级并保留其他渠道 |
| WebSearch | 零登录 | 每关键词 ≥3 条结果 | 标题/URL/摘要/来源域名 | 主题词质量校验通过（防降级页）；知乎内容可覆盖（关键词含"知乎"时出现 zhihu.com 结果） | 降级 |
| 微博 | Cookie | 每关键词 ≥3 条微博 | bid/作者/正文/URL/时间/转发/评论/赞 | 评论（启用时）≥1 条；Cookie 失效 → 错误含"Cookie"触发弹窗重粘 | 降级 + 重粘提示 |
| 小红书 | Chrome 登录态 | 每关键词 ≥1 条笔记（详情正文非空） | 笔记ID/作者/标题/正文/URL(xsec_token)/日期/点赞/收藏/评论数 | "万"格式点赞正确解析；评论（启用时）≥1 条；无 opencli/未登录 → 明确错误 | 降级 |

**通用验收**：四重去重生效；单渠道失败不影响整体流程；进度回调正常；时间范围过滤有效（若设置）。

## 三、结论

**四渠道全部通过验收**，可进入阶段二（分析质量打磨）。

遗留问题与建议：
1. **WebSearch 关键词策略**：品牌纯词返回官网类结果；建议关键词生成时对 WebSearch
   自动追加"评价/怎么样"等后缀（放入阶段二关键词调优）。
2. **小红书运行依赖**：需要 Chrome 保持小红书登录态 + opencli；断会话时渠道自动降级
   并给出明确提示（已实现）。
3. **微博 Cookie 时效**：Cookie 过期会自动弹窗重粘（已实现），无人工干预风险。
4. **数据落盘**：本次试跑产物位于 `data/reports/验收试跑_20260804_190639/`
   （Excel 3 sheet + result.json），data/ 目录不入库。

## 四、2026-08-05 整改与复验（v2）

针对验收反馈的 4 个问题逐一整改并复验（`data/reports/验收试跑v2_20260805_013458/`）：

| 问题 | 整改 | 复验结果 |
|------|------|----------|
| 1a. 评论只见第一条 | Excel 新增**评论明细 sheet**（每条评论一行）+ 原始数据新增**已采集评论数列**（区分平台总评论数 vs 已采集数） | 评论明细 20~21 行/品牌，完整展示作者/内容/点赞/时间 |
| 1b. 无采集量控制 | 向导按渠道设置**每关键词条数上限** + **每帖评论上限**，确认页显示**预计采集量与耗时** | 恋与深空 20 帖/21 评论、华润万家 17/19、大疆 20/20 |
| 2. 情感判定不准 | ① 词典新增网络情感词 + **反讽降置信**启发式；② 修复**正负抵消导致的高置信中性** bug；③ **LLM 精分析默认开启**（有 Key 时）+ 提示词加反讽识别指导 | 三个示例文本实测：反讽→negative、天呐→positive、追责→negative（LLM 修正）；混合流水线基准 80.9%→**90.0%** |
| 3. 维度/叙事/归因空 | 验收改为**按品牌设置领域**（game/consumer）+ 开启叙事归因（LLM 门控） | 恋与深空 维度 3/叙事 2/归因 2、华润万家 6/6/6、大疆 7/10/10 |
| 4. WebSearch 官网无信息 | WebSearch 拆分为 **websearch / websearch_zhihu / websearch_tieba / websearch_taptap** 四个渠道（关键词提示+域名过滤，实测命中 7/7、5/7、5/7） | 知乎话题页、贴吧帖、TapTap 论坛/评分页均抓到 |

> 说明：维度仅对命中领域 schema 关键词的文本打标（覆盖率取决于 schema 词表，属阶段二
> 分词与领域词调优范畴）；叙事/归因只对 LLM 精分析过的文本执行（成本控制设计）。
