# 使用边界与合规说明

> 版本：v1.0 | 2026-08-06

## 一、预期用途

- 个人研究、市场/竞品舆情观察、产品体验分析等**非商业诽谤、非攻击性**用途。
- 分析结果仅作参考，不构成投资、公关或经营决策依据。

## 二、数据来源与合规

- 本工具使用各平台**公开接口/公开搜索结果**（B站公开 API、360/Bing 搜索、
  m.weibo.cn 登录态、opencli 复用 Chrome 会话）。
- 请遵守各平台服务条款与频率限制：**避免短时间高频请求**（微博风控最严，
  严重时可封号；小红书高频会触发验证码，甚至影响登录态）。
- 不抓取非公开内容，不绕过登录/付费墙。

## 三、账号与数据安全

- 微博 Cookie 是账号凭证：默认只存于当前会话；如勾选"记住 Cookie"，
  会以 **Windows DPAPI 加密**保存到本机 `data/secrets/`（仅当前用户可解），
  该目录已在 `.gitignore` 中，**不会入库、不会上传**。
- LLM API Key 本地明文文件（`llm_apikey.txt`）请勿提交到任何仓库；
  正式分发版应由使用者自行填写。
- 清除本地凭证：向导里点"清除已保存的 Cookie"，或删除 `data/secrets/`。

## 四、免责声明

- 采集到的内容版权归原作者/平台所有，仅用于个人分析，请勿二次传播或商用。
- 情感分析（词典/大模型）存在误差，尤其反讽、方言、行业黑话场景；
  样本量小、丢弃率高时结论可信度有限（报告已展示可信度标注）。
- 使用本工具产生的账号风险、平台处罚或法律纠纷，由使用者自行承担。

## 五、后续正式分发提醒

- 打包发布前需在界面内置本说明，并在首次使用时让用户确认；
- 若转商用，需重新评估平台条款与内容使用授权。
