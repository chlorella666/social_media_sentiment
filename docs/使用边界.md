# 使用边界与合规说明
> 版本：v1.2 | 2026-08-19

## 一、预期用途

- 个人研究、市场/竞品舆情观察、产品体验分析等**非商业、非攻击性**用途。
- 分析结果仅供参考，不构成投资、公关或经营决策依据。
- 首次启动应用会展示本说明并要求确认；确认记录（版本+时间）仅存本机，
  侧边栏可随时回看。实质性条款变更后需重新确认。

## 二、数据来源与合规

- 本工具使用各平台**公开接口/公开搜索结果**（B站公开 API、360/Bing 搜索、
  m.weibo.cn 登录态、opencli 复用 Chrome 会话）。
- 请遵守各平台服务条款与频率限制：**避免短时间高频请求**（微博风控最严，
  严重时可封号；小红书高频会触发验证码，甚至影响登录态）。
- 不抓取非公开内容，不绕过登录/付费墙。

## 三、账号与数据安全

- 微博 Cookie 是账号凭证：默认只存于当前会话；如勾选"记住 Cookie"，
  会以 **Windows DPAPI 加密**保存到本机 `data/secrets/`（仅当前用户可解），
  该目录已在 `.gitignore` 中，**不会入库、不会上传**。
- 结果页「这条判错了」反馈（含原文摘录）仅存本机 `data/app.db` 的反馈表，
  不离开本机；侧边栏"一键清除全部数据"可一并删除。
- LLM API Key 同样以 **Windows DPAPI 加密**存于本机 `data/secrets/`
  （仅当前 Windows 用户可解密），不落明文、不入库、不上传；
  应用运行链路只从本机加密存储读取 Key。换机/重装系统后需重新填写。
- 清除本地凭证：侧边栏可分别"清除已保存的 API Key"和"清除已保存的 Cookie"，
  或删除 `data/secrets/` 目录。

## 四、LLM 数据出境说明

- 开启 LLM 精分析后，**低置信度文本会发送给所选服务商**（DeepSeek/OpenAI 等）
  用于情感分析，这是本工具最大的数据出境点；调用前应用会对 URL、@提及、
  手机号等可识别信息做脱敏。
- 请勿在分析内容中夹带个人敏感信息（姓名、手机号、身份证、账号密码等）。
- 不开启 LLM 精分析时完全离线运行（词典模式），不会向任何第三方发送文本。

- 采集到的内容版权归原作者/平台所有，仅用于个人分析，请勿二次传播或商用。

  样本量小、丢弃率高时结论可信度有限（报告已展示可信度标注）。

以下结论基于检索当日官方公开条款，仅作产品使用边界说明，不构成法律意见；
条款可能更新，正式分发前建议复核。

### 6.1 DeepSeek 开放平台

- 依据：[《DeepSeek 开放平台服务协议》](https://cdn.deepseek.com/policies/zh-CN/deepseek-open-platform-terms-of-service.html)
  （2026-04-22 更新）。
- 条款 4.2 明确：**您保留对输入内容中您拥有的权利**；服务商未在协议中取得
  将输入用于模型训练的一般性授权。
- 条款 3.5 要求开发者作为个人信息处理者，向终端用户披露数据处理情况——
  本文件即承担该披露义务，确认页首次展示并要求确认。

### 6.2 OpenAI API

- 依据：[OpenAI 官方数据使用说明](https://openai.com/index/response-to-nyt-data-demands/)
  （2025-10-22）。
- API 输入/输出**不用于训练模型**；输入/输出内容在 30 天后自动删除
  （法律强制保留情形除外）。
- 采用 Zero Data Retention 的客户，OpenAI 不存储其输入/输出。

### 6.3 与本工具行为的对应关系

- 本工具默认离线（不开启 LLM 精分析时无任何数据出境），与"输入不用于训练"
  的条款结论叠加，数据风险最小化；
- 开启 LLM 精分析时：调用前已对 URL/@提及/手机号等做脱敏；请勿主动输入
  个人敏感信息（见第四节）；API Key 仅存本机且加密（见第三节）。
- 若未来更换或新增服务商，应复用本节口径重新核实条款后再上线。
