## 二、三类处置（按依赖排序）

### 处置 1：口径复核（V2 纪律，不花 LLM 跑分，先行）

C/D/E 共 5~6 条是**主集 gold 与边界集定版口径冲突**（边界集 2.3 定版："emoji 不单独
构成情感依据→neutral"、"广告→neutral"；主集这些行 gold=positive）。这是标准答案口径
不一致，**不该用 prompt 硬适配可疑 gold**：

1. 我生成《主集正面口径复核表》（5~6 行，含原文/gold/边界集同款判例对照）；
2. 你逐条表态：保留 positive（粉丝语境视为正面）或改 neutral（对齐边界集）；
3. 修订走 V2 流程：gold 修订列「是否参考过模型判定」= 否（这是口径讨论，不是模型错误
   修订）；M3 与主集维度基线重冻结一起升级 golden_set。

**处置 1 落地（2026-08-15，用户已表态）**：1~4 条（纯笑声/emoji ×3、代言广告帖 ×1）
改 neutral；第 5 条（反讽式夸赞）保持 positive、remark 标记"待复核"。golden_set 升
v1.2（新增 gold_revised_by_model 列，4 条=否），指纹变化 → 主集混合基线待 LLM 重跑后
重冻结（预期机制）。**正面召回基线重算**：positive n=50→46，pv7 判定正确 34 →
recall **73.9%**，目标 80% = 37/46（再救回 3 条）。

### 处置 2：词典层第一刀（正名黑话/情绪词表）

修复 4 条词典直判错 + 降低同类复发（按"词典增强=提准类"验证：主集+边界集双跑 +
3C 防退化 + 人工抽检；3C 词典改动挂 3C hold-out）：

| 词/短语 | 语境含义 | 词典动作 |
|---|---|---|
| 开荤（了） | 粉丝语境=新鲜/刺激的兴奋，正面 | 加入正面黑话表（仅"粉丝/内容"语境，不覆盖"开荤=破戒"其他义） |
| 甘拜下风 | 夸角色/内容=佩服，正面 | 正面词 |
| 闹麻了（四川方言） | 很热闹/很兴奋，正面 | 正面方言词 |
| 有梗 | 有趣，正面 | 正面词 |
| 心疼/苦命（哥） | 剧情共鸣=玩家正面投入，非对产品负面 | 弱化负面权重 + 命中"角色/剧情语境"时转正面或降置信送 LLM |
| 酸涩/成长的痛 | 同上 | 同上 |
| 笑疯（了） | 娱乐语境=正面反应，非嘲讽（对照 2.3 反讽规则二分） | 语境词表 |

**处置 2 落地（2026-08-15，已实现并本地验证）**：

- 根因修正：误判负面并非缺词，而是 **ECSD 电商词典单字词在长词内子串误伤**
  （"恋与深空"→空、"暗戳戳"→暗、"乱成一锅粥"→乱、"酸涩"→涩，命中即高置信负面）；
- 改动：ECSD 单字词不再直接进评分 → 改为**精选单字表**（牛/爽/帅/美/甜/香/强/稳/棒/
  快/神/灵/亮/省/准/值 + 坏/丑/烦/破/疼/漏/裂/渣/碎/臭/慢/脏/吵）→ 永久排除高碰撞
  噪声字（空/暗/涩/旧/乱/疯/苦/痛/卡/松/干等）→ 新增粉丝向黑话（开荤/甘拜下风/
  闹麻了/有梗/星星眼）→ "一样"归入语境词；
- 收口版（2026-08-15 终版）：中间版实测暴露"官方/介绍/活动文本被直判正面"（主集
  12 条 + 边界集 lowconf 10 条），修复 = 官方/介绍/评测语体标记压置信送 LLM +
  移除高碰撞单字正词（帅/美/强/棒/快/神/灵/亮/省/值）+ "差别"归语境词；
- **混合验证 6 轮（V3 判定全部达标）**：主集 83.4/82.3 → 82.9%（正面召回 81.5%
  达成目标 80%，precision 0.755）；边界集 88.6/88.2 → 88.4%（lowconf 恢复 91.5%）；
  3C 73.6/72.2 → 72.9%（vs 基线 73.6%，不回退）；主集混合基线 v1.3 冻结 82.86%；
- **处置 2 收口**：主集正面召回专项目标已由词典层达成（提示词 v3.3 降级为可选再提升，
  等口径/难例/hold-out 补强时再做）。

### 处置 3：LLM 层 few-shot + 规则（Prompt v3.3，PROMPT_VERSION=8）

**只加"正面召回"要点，不动 3C neutral 语体规则**（3C 规则针对介绍/开箱/标题页，
与粉丝/剧情语境不重叠）。新增要点：

1. **情绪共鸣 ≠ 对产品负面**：粉丝/剧情语境下的"心疼/泪目/酸涩/意难平"表达的是
   对内容/角色的喜爱与投入，整条情感按正面；只有明确批评产品/玩法/服务的负面才算
   negative；
2. **娱乐反应词二分**："笑疯/笑死/闹麻了/乱成一锅粥" 在娱乐/粉丝语境=正面（内容有趣、
   评论区有梗）；在嘲讽/翻车语境=负面（沿用 2.3 反讽规则）；
3. **隐晦夸赞识别**：调侃式夸赞（"好大的厚底鞋"）、期待/安利（"联动皮肤就有意思了"、
   "第一个新动静"）、"贬友商=抬本品牌"（"友商想进赛道但黑稿没了"）均按正面；
4. **黑话正名提示**：开荤/甘拜下风/有梗/星星眼 等粉丝向黑话按正面，不按字面。

**Few-shot 判例（6 条，进 system prompt）**：

| 原文（脱敏） | 判定 | 理由 |
|---|---|---|
| 啊……我那苦命的哥，真让人心疼 | positive | 剧情共鸣，玩家对角色正面投入 |
| 也够游戏闹麻了[星星眼][星星眼] | positive | 方言"闹麻了"=很热闹兴奋，粉丝正面 |
| 这大苹果肌这手段，甘拜下风啊哥哥！！ | positive | 粉丝夸赞角色 |
| 哥哥穿了一个好大的厚底鞋 | positive | 粉丝调侃式夸赞 |
| 友商想进入的赛道，可惜直播撞机，黑稿就没了[大笑] | positive | 贬友商=对本品牌/赛道正面 |
| lysk评论区给我笑疯了，大家还是太有梗了 | positive | 娱乐语境"笑疯/有梗"=正面反应 |

> 判例 6 修正（2026-08-15 口径复核后）：原"笑声/emoji 在粉丝语境=正面"取消——
> 主集 gold 已按边界集口径改 neutral；规则改为"笑声/emoji 不单独构成情感依据 →
> neutral"。粉丝向正评识别聚焦情绪共鸣/调侃/隐晦夸赞（判例 1~5），不再扩到笑声。

## 三、验收与止损（证据组合，2026-08-15 确认口径）

1. **主集**：positive recall 两轮均值 ≥ 目标 80%，且 precision ≥ 0.65；
   整体准确率 vs 基线 77.71% 非回退（V3 status）；
2. **跨领域**：边界集 vs 81.82% 非回退（尤其 emoji/irony 子集）、3C vs 73.6% 非回退；
3. **hold-out**：到位后叠加"同向提升且超 CI"（3C hold-out 先行）；
4. **人工抽检**：我出错误样本清单，你确认无系统性新误判（尤其"笑声全判正面"类过冲）；
5. **止损**：两轮无同向提升即停，回到 v3.2（PROMPT_VERSION 常量保留旧版）。
