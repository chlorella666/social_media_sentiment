# 用户隐私政策（面向公开分发）

> 版本：v1.0（2026-08-22）| 状态：待公开前定稿（todolist 4.7）
> 配套：[使用边界](使用边界.md)（产品内确认页）· [BRD](BRD.md) §9 合规数据流 · GitHub公开执行方案

## 1. 适用范围与基本承诺

本政策适用于本工具（本地版）。**默认本地处理**：采集内容、报告、凭据默认只存在于使用者本机；未开启 LLM 时不发送任何文本到第三方。

## 2. 收集与存储

| 数据 | 存储 | 说明 |
|---|---|---|
| 采集内容（帖子/评论） | 本机 `data/` | 用于分析与报告，可一键清除 |
| 报告产物 | 本机 `data/reports/` | Excel/HTML/Word/result.json |
| 渠道凭据（Cookie/API Key） | 本机 DPAPI 加密（`data/secrets/`） | 仅本机读取，不上传 |
| 使用日志 | 本机 `data/logs/` | 结构化日志与未来埋点（本地） |

## 3. 数据出境（两类出网点）

1. **采集请求**：向微博/小红书/B站/WebSearch 等平台请求公开数据；凭据仅在本机携带，不外传；
2. **LLM 调用**（可选）：开启后，低置信度文本经脱敏（去用户名/手机号/邮箱/链接等）发送给所选服务商（DeepSeek/OpenAI 等）；关闭 LLM 则完全不发生。

## 4. 用户权利

- 查看与导出：报告与数据均可从应用内导出；
- 删除：应用内"一键清除"删除采集数据、报告、已存凭据（P1-4）；
- 确认与撤销：《使用边界》首次启动确认页，可随时回看。

## 5. 第三方说明

- LLM 服务商数据条款：DeepSeek 见其官网 API 条款；OpenAI 留存约 30 天后删除（《使用边界》v1.2 六节，附官方链接）；
- 平台方数据以各平台条款为准，本项目仅使用用户自备凭据的公开接口。

## 6. 免责与合规

- 使用者须遵守平台条款与适用法律；导出物含个人可识别信息，仅限内部使用、禁止二次传播；
- 本项目不包含任何绕过平台防护的技术；
- 本政策与《使用边界》联动更新，版本变化会在应用内重新确认。
