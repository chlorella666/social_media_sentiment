## 口径补充（2026-08-12 定版：关键词效果 · 受控对照 · 清洗修订）

### 评测中心指标口径（2.1，2026-08-10 定版，归档补充）

- 主评分/情感类别：整体准确率 + 每类 P/R/F1（one-vs-rest）；负面召回为场景 A
  （负面突变监控）核心指标；
- 对比：Δpp 较上次（同模式 + 同 golden 指纹）与冻结基线（词典 0.3543 / 混合 0.7829）；
  |Δpp| < 1pp 视为持平；细分 n < 30 标"参考"；
- 短板：渠道/领域/情感类别 n≥30 且准确率 <75% 标记短板；负面召回 <60% 提示为重点提升项。

### 关键词效果口径（2.2，2026-08-11 定版）

- 采集 = 保留帖子 + 该关键词/查询串的丢弃记录；有效供给率 = 保留 / 采集；
- 归因键：(渠道, 关键词, 实际查询串)；实际查询串 = 确认关键词 + 子渠道提示 + 自动后缀
  （来源 `platform_specific.query`，2.2 埋点后记录；旧数据无 keyword/query 时按关键词
  兜底，无法归因的进入"未归属丢弃"单独计数）；
- 编码与负面数按 (渠道, 关键词) 归因；LLM 费用按编码文本数均摊估算；
- 证据门槛：单查询串样本 n<30 仅参考；候选词需人工确认
  （同义词每品牌 ≤2、额外查询 ≤5、后缀池 ≤5）。

## 2026-08-13 受控对照口径修订（分档判定）与品牌 2 判定

### 修订原因

- 基准整体有效率接近天花板（≥85%）时，"整体 +5pp"在数学上不可达：任何有效率
  <100% 的新查询都会稀释整体率（小象超市 100%→92.9% 即为组成效应，非质量下降）；
- 因此按基准水平分档判定，避免"高基线品牌永远无法验证加词有效"。

### 分档判定口径（2026-08-13 定版，替代单一 +5pp 口径）

| 口径 | 适用 | 判定条件 |
|------|------|----------|
| 提升验证 | 基准整体有效率 <85% | 整体有效率较基准 ≥ +5pp，且纯品牌词丢弃率 <15% |
| 扩容验证 | 基准整体有效率 ≥85%（近天花板） | 同查询串有效率不降（±1pp 内）＋ 新增查询串有效率 ≥80% ＋ 有效文本增量显著（新增保留 ≥30 条或相对增长 ≥50%），且纯品牌词丢弃率 <15% |

- 样本门槛：判定所用查询串 n≥30；基准 n<30 标"参考"，不单独构成硬结论。

### 小象超市聚合确认（2026-08-13，跨任务去重口径复核）

- 方法：同一配置（WebSearch 仅、limit=13、2026-07-14~08-13）追加 3 轮任务；
  发现跨任务直接求和会重复计数同一批 URL（9 轮「评价」12→72，去重后实为 12），
  判定口径修订为**跨任务按 URL（或标题前 50 字）去重**后再统计 n 与有效供给率；

  （先去重后 n≥30 且全部新增词 ≥80%）。
