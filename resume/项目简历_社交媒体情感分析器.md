产品负责人 & 全栈实现（个人独立完成） | 在线演示: https://chlorella666.github.io/social_media_sentiment/ · GitHub: https://github.com/chlorella666/social_media_sentiment

- **需求洞察与产品定位**：面向个人创作者、小团队与品牌方市场人员，识别"商业舆情工具年费门槛高、人工整理不可持续、分析质量不透明"的核心痛点；将模糊目标拆解为"品牌→关键词→渠道→报告"6 步向导与 P0/P1 优先级，明确"单次分析"产品边界（监控/多期对比/网页版延后），产出 PRD、技术方案与验收标准。
- **任务流与机制设计**：设计"采集→清洗→词典预筛→LLM 精分析→证据链报告"五段式分析管道与领域维度体系（内容/实物/服务模板组合 + 自定义维度）；构建"词典直判降本 + 低置信度送 LLM + 难例人工复核"的混合路由，将开放式 LLM 生成转化为可控的结构化任务流（轻量 agent 实践）。
- **交互与信息架构设计**：以"结论优先"重构结果页信息层级（结论胶囊 → 指标卡 → 图表钻取 → 下载区），补齐采集透明度说明、错误分级提示与"需复核"人工闭环；面向小白提供演示数据、图文指引与使用边界确认页，5 分钟可出第一份报告。
- **稳定性与质量优化**：自建黄金集/边界集评测体系与冻结基线门槛，词典直判准确率从 35.4% 提升至 50.9%（+15.5pp）、LLM 混合流水线 84%–89%；通过置信度校准、风控指数退避、配额预扣回填与崩溃恢复提升稳定性，配套 38 项自动化测试 + 一键回归 + 双平台 CI。
- **上线与数据闭环**：完成端到端开发并对外公开（GitHub），内置演示报告，累计生成 60+ 份分析报告；基于关键词效果数据持续迭代采集策略，形成"采集→分析→效果→策略"的数据闭环。

## 面试口径（防追问）

- 50.9% 是**三分类整条情感准确率**（含难判的中性类），不是正负二分类；91.6% 是另一套在线公开基准的词典迭代对比，与黄金集口径不同，不要混用。
- 被问"为什么词典只有 51%"：中性样本占比高、难例多，因此设计"低置信送 LLM + 需复核闭环"，混合后 84%+，这正是该管道的价值。
- "60+ 份报告"来自本地运行产物；GitHub 仓库已公开，含小白向 README 与双平台 CI 徽章，可现场演示（demo 数据 1 分钟出报告）。

## 附：动态产品视频 / HTML 方案评估

### 目标
为简历/作品集提供一个"动态展示"：观众 1–3 分钟内看懂产品是什么、怎么用、结果长什么样。

### 三条路线对比

| 方案 | 形式 | 成本/时间 | 可复用素材 | 适合场景 |
|---|---|---|---|---|
| A. 动态 HTML 展示页 | 单文件自包含页面（CSS 动效 + 真实图表 + 步骤演示），可挂 GitHub Pages | 低（半天–1 天） | `design_entries/ui-designer/` 原型 HTML、`design_tokens.css`、Plotly 图表、演示报告截图 | 简历链接、作品集首页、发给面试官 |
| B. 录屏演示视频 | 本地跑 demo 任务（1 分钟出报告）+ 系统录屏（Win+G / OBS）+ 简单剪辑字幕 | 低–中（半天录制 + 1 天剪辑） | demo 渠道、6 步向导、结果页图表 | 视频链接 / 嵌入 HTML |
| C. AI 动画视频 | 用 AI 视频工具生成产品宣传动画 | 中–高（工具成本 + 可控性低） | 设计令牌、截图 | 视觉冲击优先，内容可控性差 |

### 推荐路线

1. **先做 A（HTML 展示页）**：素材全在仓库里，做成"点开即演示"的单页——标题/痛点 → 6 步流程动效 → 真实报告图表滚动 → GitHub 链接。纯静态 HTML/CSS/JS，无需构建工具，推 GitHub Pages 即可访问。
2. **再做 B（录屏）**：用演示数据（云朵咖啡）跑一遍完整流程录制；HTML 页可直接当视频台本与封面素材。
3. C 视需要再评估（可作为后期润色）。

### 可行性要点

- 项目已具备：确定性 demo 数据（不依赖账号，1 分钟出报告）、Plotly 离线图表（可导出 PNG / 交互 HTML）、设计令牌与原型 HTML、GitHub 仓库（Pages 可托管）。
- 注意：所有录屏/截图只用 demo 数据，不出现真实 Cookie、API Key 与真实用户数据（合规）；视频建议 ≤90 秒，聚焦"输入品牌 → 看报告"；HTML 页不要嵌入整个 Streamlit 应用（重且依赖 Python 环境），用静态图表与动效模拟即可。
